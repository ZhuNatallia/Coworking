# OfficeCare

Приложение для регулярного обслуживания офисов-коворкингов: визиты по расписанию, чек-листы, расходные материалы и список «Взять с собой».

Работает как сайт с иконкой на домашнем экране (PWA): Android, iPhone и компьютер по одной ссылке, без магазинов приложений.

## Запуск на компьютере

```bash
npm install
npm run seed     # демо-данные: города, офисы, сотрудники, визиты
npm run dev      # http://localhost:3000
```

Без настроек Supabase приложение работает в **локальном режиме**: данные лежат в `.data/db.json`. Этот режим нужен для разработки и проверки. Для работы нескольких сотрудников нужен Supabase.

## Подключение Supabase

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. В разделе **SQL Editor** выполните файл [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql).
3. Скопируйте `.env.example` в `.env.local` и заполните ключи из **Project Settings → API**, а также `SESSION_SECRET`.
4. В **Authentication → URL Configuration** укажите адрес сайта (Site URL) и добавьте `<адрес>/reset-password` в Redirect URLs — это нужно для письма «Забыли пароль».
5. Выполните `npm run seed`, чтобы создать демо-данные и пользователей. Для чистого старта создайте только администратора: `npm run seed -- --admin-only`.

## Публикация

Удобнее всего [Vercel](https://vercel.com): импортируйте репозиторий и добавьте те же переменные окружения. Сайт должен открываться по HTTPS, иначе телефон не предложит установить иконку.

## Как поставить на телефон

- **iPhone (Safari):** откройте адрес сайта → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** откройте адрес сайта → меню ⋮ → «Добавить на главный экран» или «Установить приложение».
